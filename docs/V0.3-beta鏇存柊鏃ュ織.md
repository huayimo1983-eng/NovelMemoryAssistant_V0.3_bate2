# V0.3-beta 更新日志

## 新增

- 导入中心新增 DOCX / TXT / MD 快速入库。
- 支持识别 `第1章`、`第一章`、`第一百五十一章`、`第1节`、`第一小节` 等章节标题。
- 写作包自动带出作者 IP、平台、作品类型、当前卷。
- 新增大纲防偏规则页面。
- 新增人物状态卡页面。
- 新增伏笔台账页面。
- 新增风险灯：GREEN / YELLOW / RED。
- 新增版本对比页面，支持基础段落级 diff 报告。
- 新增偏纲审查包导出。

## 当前边界

- 版本对比为基础文本对比，不是智能文学审稿。
- 风险灯为规则检查，不替代人工审稿。
- DOCX 导入会读取段落文本，不保留 Word 样式和修订痕迹。
- 暂不支持云同步。
