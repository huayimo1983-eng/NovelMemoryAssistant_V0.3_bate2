# V0.3-beta 测试清单

## 1. 基础运行

- 启动软件。
- 新建 IP。
- 新建作品。
- 关闭重开，确认数据仍在。

## 2. DOCX 导入

- 导入包含 `第一百五十一章` 的 DOCX。
- 点击“识别章节范围”。
- 确认起始章、结束章正确。
- 快速入库并设为当前有效版本。

## 3. 标准导入包

- 粘贴 IMPORT_PACKAGE 格式。
- 解析并入库。
- 检查当前有效版本与当前章节。

## 4. 写作包

- 添加大纲规则、人物状态、伏笔。
- 生成写作包。
- 确认写作包包含大纲锁定区、人物状态卡、伏笔台账和风险提示。

## 5. 版本对比

- 导入两个版本。
- 进入版本对比。
- 生成报告。
- 导出报告。

## 6. 防跑偏

- 当前章节到 10、20、30 等整十章时，检查是否提醒联合审查。
- 创建 20 章未推进的伏笔，检查是否出现风险提示。

## 7. 旧包过期

- 基于旧当前版本生成写作包。
- 导入新版本并设为当前有效。
- 确认旧写作包过期。
